# Mesh Tracker
A Mesh Tracker based on Meshtastic, in the form of a compass!

## Features
- LCD For graphics
- Battery and Built-In Charger
- 9 Axis IMU (6 Axis + Magnometer)
- BLE, WiFi, LoRA
- Nearby Pairing

## How it works
Uses LoRa to transmit to the Meshtastic network on a private channel.
